## Required implementation state coverage

For each page capture initial, empty/signed-out, populated, loading, error, and completed/selected state where meaningful. State comes from deterministic fixtures; do not turn screenshot values into product defaults. For modal and result screens, add targeted screenshots beyond the seven primary views.
