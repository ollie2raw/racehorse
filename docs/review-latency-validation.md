## Interpretation

- Median wall-clock **decreased by 17.67%** (−223.46 ms) on this fixed 117-decision master-tier game.
- AFTER runs included **0** deadline-incomplete decisions, so the comparison is not confounded by F4b ceiling intervention on this game.
- Tier mix and selected best actions matched between the representative BEFORE/AFTER samples (0 best-action mismatches).
- BEFORE is in-process serial evaluation of the pre-F4a evaluator; AFTER includes worker create/loader overhead under the production pool-size policy.
- Node timing only — not a browser latency claim.
- No follow-up tuning was performed (F4c is measurement-only).

## Caveats

- Host loadavg was elevated (~5) at end of run; protocol forbids result-driven reruns.
- One BEFORE run (1985 ms) is an outlier relative to the other four; the median headline is robust to that spike.
