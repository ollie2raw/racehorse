# TestFlight QA checklist: what is already proven, what needs a physical iPhone

2026-10-18, candidate `b2c5bd92`. This is the short working list; [device-matrix.md](device-matrix.md) stays the full
two-device recording sheet and [apple-handoff.md](apple-handoff.md) the signing plan. **No physical-device validation has happened.**
Nothing below is marked passed for a device.

How to read the columns

* **Simulator evidence (executed)**: what was actually run, where, and on what. Simulator results are real but cannot stand in for a
  device on anything marked *device only*.
* **Physical iPhone, signed TestFlight build (required)**: the check that is still open. Install from **TestFlight**, not Xcode, so the Release
  build is what is tested. The Keychain session only works in a **team-signed** build (an unsigned or ad-hoc build gets error -34018 and fails
  closed to signed-out), so session persistence cannot be completed any other way.
