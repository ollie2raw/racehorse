# Auto Type Checking

## Description
Systematically run TypeScript compilation validation after file modifications to catch type safety mismatches across client and server boundaries before executing tests.

## Steps
1. **Identify type check targets** — locate the relevant configuration files (`tsconfig.json`) or build targets for the affected services.
2. **Execute validation** — run the project's type validation script or compilation command (e.g., `npx tsc --noEmit` or `npm run build`).
3. **Isolate compilation errors** — parse the compiler output to isolate specific signature mismatches, missing interface fields, or type drift caused by refactoring.
4. **Resolve downstream breaks** — fix code paths sequentially, moving outward from core data models to peripheral utilities, handlers, and client view layers.

## Rules
* Never proceed to running unit tests while compilation or type safety violations are outstanding.
* Track errors across architectural boundaries; changes to backend data structures must be reconciled with client hydration types immediately.
