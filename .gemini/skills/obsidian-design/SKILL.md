# Obsidian Design System

**Activation:** This skill activates when styling UI components, auditing layout consistency, or applying the dynamic tier-based obsidian theme.

## Core Identity Rules
* **The Foundation:** Every screen uses the Obsidian base (#04070c) for containers and backgrounds.
* **The Accents (Dynamic):** Styles must use CSS variables for accents to support tier-switching: Rookie (Emerald #4ADE80), Standard (Blue #3B82F6), Elite (Gold #E7B64A), and Master (Purple #A855F7).
* **Layout Constraint:** Hero cards (like Fritz) must be 1:1 aspect ratio.
* **Floating HUD Protocol:** Action badges must be floating capsules with a bottom-lift (e.g., bottom: 20px) and a dark scrim behind them to anchor the UI.

## Assets Reference
Use assets/theme-variables.css for the definitive list of hex codes and spacing values.
