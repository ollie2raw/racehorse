# Obsidian Design System

**Activation:** This skill activates when styling UI components, auditing layout consistency, or applying the dynamic tier-based obsidian theme.

## Core Identity Rules
* **The Foundation:** Every screen uses the Obsidian base (#04070c).
* **The Accents:** Rookie (#4ADE80), Standard (#3B82F6), Elite (#E7B64A), Master (#A855F7).
* **Layout:** Hero cards must be 1:1 aspect ratio.
* **HUD:** Badges must be floating capsules with a bottom-lift (e.g., bottom: 20px).
